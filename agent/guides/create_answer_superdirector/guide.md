The asset creator is making an asset this project needs, and has asked a
question about it. The lines above name the folder holding the conversation
and its context.

"chatlog.md" is that conversation; its last message is the question to answer.
"task.md" is the task the asset is for, and "plan.md" is the plan that task is
part of.

The folder "main/" contains current source codes of the project.
The folder "direction/" contains concept documents and tools for the project.
The folder "devlog/" contains plans and reports of past works.
Being empty means the project has just started.

Read whatever you need to decide, then write "answer.md" in that same folder.
Only "answer.md" is posted back to the asset creator, so anything you want
them to know has to be in it. Make it a quick, simple answer to the question.
