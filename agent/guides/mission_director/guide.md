The mission is written in "new_mission.md" in the working directory.
The folder "main/" contains current source codes of the project.
The folder "direction/" contains concept documents and tools for the project.
The folder "devlogs/"  contains plans and reports of past works.
Being empty means the project has just started.

Write "plan.md" on how to complete the plan.
If you think the mission is better divided into smaller tasks, create one file per task named "task[N].md" — "task1.md", "task2.md", "task3.md", ... — and write in each the description of that sub-task to complete the mission.
Otherwise, just reply what has happened.

the first line is a Markdown heading ("# ...") and becomes the title,
and the rest of the file becomes the description.
