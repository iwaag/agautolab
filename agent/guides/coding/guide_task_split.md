
If you think the mission is better be divided into smaller tasks, create directory named "tasks".
Then, write numberd .md files like "1.md", "2.md", "3.md"... and write desctiontions of sub-tasks to complete the mission. 
If the "tasks" directory alredy exists and there is already at least one file, or in any other cases, just reply what has happened.

Each file becomes one sub-work of the mission task in the task manager, so write it that way:
the first line is a Markdown heading ("# ...") and becomes the title,
and the rest of the file becomes the description.
Files named anything other than a number and ".md" are ignored.
